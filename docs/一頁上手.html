我要借東西 一般同仁

  1. 登入　開網址，輸入工號，不用密碼。
    第一次登入會請你填 Email —— 核准、歸還的通知全靠它，一定要填。
  2. 挑展品　到「展品目錄」先選借出日與歸還日，卡片上就會顯示那段期間還能借幾台，按加入。
  3. 送出　「借用申請」只要填借用目的和借用期間。工號與 Email 系統自動帶，不用再打一次。
  4. 然後你就不用再做什麼了
    核准、不核准、歸還結案，每一步都會寄 Email 給你。
拿東西：核准信寄到就可以去現場拿，不用再回系統簽收。
還東西：交給管理者，他登記完你會收到結案信。

小提醒

  • 填錯了 → 「我的借用」按 修改申請（核准之後要找管理者）
  • 不借了 → 待審核時按 取消申請
  • 要延期 → 跟管理者說，他可以直接幫你改歸還日
  • 東西要給別的同事用 → 請他自己開一張單，系統沒有「轉借」這個動作
  • 要紙本簽名 → 單子上按 列印
  • 公用電腦記得按右上角登出

「我的借用」上的狀態是什麼意思

待審核單子送出去了，等管理者看。這時候還可以自己改或取消。
出借中已經核准，東西算在你手上了。去現場拿（或已經拿了），還的時候交給管理者。
已歸還管理者登記完了，結案。
已駁回沒核准，信裡會寫原因。要改就重開一張。
過了歸還日還沒還＝逾期。系統會一直把它算成佔用，別人就借不到那幾台 —— 還不了的話先跟管理者說一聲延期。

我管展品 展品管理者

⚠ 按下「核准」＝ 東西交出去了。 單子直接變「出借中」，庫存立刻扣掉、逐台編號也當場綁好。 先確認東西真的在架上、人也來拿了再按。
  • 按錯了 → 對出借中的單按 取消核准，綁定的編號會放回架上。已經登記過歸還的不行，改用登記歸還。
  • 東西還回來 → 登記歸還：填還幾台 / 其中損壞幾台 / 短少幾台，還可以選還到哪一個廠區。損壞的東西還算在庫存裡，只是留個記號。
  • 口頭借用 → 「借用申請」勾 代為登記，直接變出借中。工號要對得到真帳號，不然通知寄不到他。
  • 一次核准很多張 → 待審核超過兩張會出現批次列，數量不夠的會被跳過並告訴你原因。
  • 下架 vs 刪除 → 暫時不用就下架（紀錄都在，隨時上架）；借過的展品刪不掉。
每一步都會同時寄信給申請人和按下按鈕的你，兩邊留底。

我只是想看一下 主管

  • 總覽：展品品項 / 總件數 / 倉庫在庫三塊磚，點得開看各廠區數字。
  • 今天要做的事：逾期未還、待審核、今天到期、已停用的人手上還沒還的單，都收在總覽最上面。
  • 匯出庫存表：總覽右上角一鍵匯出，可以直接給人。
  • 東西在誰手上：借用單與盤點頁都查得到，盤點時「借出中」的會另外列，不用盤也不算短少。
  • 整場展覽：「展覽檔期」可以把一場展覽底下的好幾張單管在一起，確認檔期之後，還沒開單的部分會先幫你把庫存卡住，不會被別人借走。
  • 系統不會自己改庫存：展後結算把「規劃 / 借出 / 已還 / 短少 / 未還」攤開給人看，追討還是人的事。

常見問題

一直要我填 Email？　沒有 Email 就收不到任何通知，填一次就好。
查無此工號？　請管理者把你加進人員名冊。
可借數量比倉庫少？　被別張借用單或展覽卡位佔住了。出借中的單從今天就開始佔，不是從借出日才算。
核准時說「現在只有 N 台在庫」？　那個廠區實際不夠這張單要的量，先確認實物。
管理者 PIN 一直錯？　連錯 5 次會鎖 10 分鐘，等一下再試。
畫面怪怪的 / 數字不對？　重新整理一次。系統換版時會自己跳出「立即更新」。
