# 展品管理系統 使用說明(一般版)

## 同仁
1. 打開網址,輸入**工號**即可進入(不需密碼)。
2. **展品目錄**:展品依分類分段(eReader、eNote、Logistics & Factory、Prism、Signage、Lifestyle、Mobile & Wearables…),上方籤條可以只看某一類。每項看得到「倉庫在庫 / 出借中 / 已預約」,選日期可看該期間還能借幾個。
3. **借用申請**:把要用的展品加進來、選日期 → 系統標出每項「足夠 / 缺幾個」→ **只要填「借用目的」和借用期間**就能送出。聯絡方式(工號 / Email)系統會自己從你的帳號帶上去,不用再打一次。
4. **送出之後你就不用再做什麼了。** 核准、不核准、歸還結案,每一步都會寄 Email 給你。
   - 管理者按下核准的那一刻,東西就算交給你了(單子直接變成「出借中」),去現場拿就好,不用再在系統上簽收。
   - 還回去的時候交給管理者,他登記完你就會收到結案信。
5. **填錯了**:在「我的借用」按「修改申請」直接改,不用取消重來(核准之後就要找管理者)。
6. **展期延後 / 想轉給同事**:直接跟管理者說,由他在系統上處理。
7. **第一次登入系統會要你填 Email** —— 不填收不到上面那些通知,所以不能略過。
8. 用公用電腦記得按右上角「登出」。

## 展品管理者
- **總覽**:庫存數字、待審核、逾期、近期到期、已停用的人手上還沒還的單。「匯出庫存表」可直接給主管。
- **借用單**:審核、登記歸還、延期、列印。待審核超過兩張時上方會出現批次列,勾選後**一次核准**(不足的那幾張會被跳過並告訴你原因)。
  - ⚠️ **按下核准就等於把東西交出去了** —— 單子直接變成「出借中」,逐台編號也會自動綁上去(只挑那個廠區在庫的)。所以**核准之前先確認實物真的在架上**。那個廠區台數不夠的話系統會擋下來。
  - 核准錯了可以對「出借中」的單按「取消核准」,東西會放回架上;但**只有在還沒登記過任何歸還的時候**才行。
  - **登記歸還**可以填「還了幾台 / 其中損壞幾台 / 短少幾台」,還可以選還到哪一個廠區。損壞的東西還算在庫存裡,只是留個記號。
- **今天要做的事**:總覽最上方一張清單,逾期、待審核、今日到期、已經停用的人手上還沒還的單都在這裡,點一下直接過去。
- **列印借用單**:卡片右下「列印」,含品項清單與雙方簽名欄,現場簽收或給主管看都可以。
- **代為登記**:口頭借用時,在借用申請勾「代為登記」並填借用人工號,直接成為「出借中」。⚠️ **工號要對得到系統裡真實的帳號**,而且那個帳號要有 Email —— 不然那張單沒有主人,對方也收不到任何通知,系統會擋下來。
- **展品管理**:依分類分段的清單;新增 / 批次匯入展品、單台編號、列印 QR 標籤。每個分類標題右邊有「加到這一類」。
- **展品照片**:編輯展品時按「選照片 / 拍照」,手機會直接開相機或相簿,電腦會開檔案選擇。系統自動縮圖後存進雲端硬碟,不用先上傳到別的地方。也可以改貼網址,或按「移除照片」。
- **存放位置**:下拉選單,預設新竹、林口;要加別的地點選「+ 新增地點…」,之後就會出現在清單裡。
- **同一個展品放在兩個廠區**:編輯展品時用「各地點的數量」分開填(新竹 2、林口 3),按「再加一個地點」加一列。清單上會顯示「新竹 2 · 林口 3」。
- **借的時候要選從哪一點借**:目錄卡片上如果有地點下拉,就選你要拿的那一區;數量是分開算的,新竹借光不影響林口。
- **還的時候可以選還到哪一區**:預設還回原本借出的那一點,選別的就代表東西搬到那一區了。
- **盤點先選廠區**:只會列出那一區該有的東西,不用管別區的。
- **下架還是刪除?** 暫時不用 → 下架(紀錄都還在,隨時上架)。建錯了、從來沒借過 → 編輯視窗左下角「刪除展品」,會連單台編號一起移除。**借過的刪不掉**,系統會擋下來叫你改用下架。
- **分類管理**(展品管理右上角):新增、改名、調順序、停用分類。預設七類:eReader、eNote、Logistics & Factory、Prism、Signage、Lifestyle、Mobile & Wearables。改名時底下的展品會跟著走;還有展品的分類不能停用,要先把展品改到別類。新增展品時也可以直接在分類下拉選「+ 新增分類…」。
- **盤點**:依分類分段,可以只盤一類(例如今天只盤 Signage)。上方一排總計:已盤幾項、應在庫幾件、實際點到幾件、差異、借出中幾件。數量品項填實點數、逐台品項掃描或勾選,差異即時算出來。**借出中的會另外列出來(在誰手上、哪天還),不用盤也不會被當成遺失**。最後可一鍵套用差異。
- **使用者**:匯入人員名冊、設定管理者(需 PIN,對方首次登入須自行更改)。

## 常見問題
| 問題 | 解法 |
|---|---|
| 查無此工號 | 請管理者把你加進名冊 |
| 核准時說「現在只有 N 台在庫」 | 那個廠區實際在架上的不夠這張單要的量。先確認實物,或請對方改單 |
| 登入時一直要我填 Email | 帳號上沒有 Email 就收不到核准 / 歸還通知,填一次就好 |
| 管理者 PIN 說不正確 | 連錯 5 次會鎖 10 分鐘 |
| 可借數量比倉庫少 | 已經被其他借用單或展覽卡位佔住,或有逾期未還。**出借中的單從今天就開始佔**,不是從它的借出日才開始 |
| 分類停用不了 | 底下還有展品,先把它們改到別的分類 |
| 盤點時數字對不上 | 「應在庫」已扣掉借出中的量,借出去的不用盤;卡片旁邊有列是誰借走的 |
